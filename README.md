# Stack Neverflow

**Tasks stack up, but never overflow.**
*Your windows. Your tasks. One organized desktop.*

**스택 네버플로우** (이전 이름: 창 더미 / Window Piles). 실행 중인 여러 앱 창을 '더미'로 접어 화면에 남겨 두고, 다시 원래 창들로 펼쳐 쓰는 초경량 Windows 유틸리티. 화면을 책상처럼, 창 더미를 서류 더미처럼 다룹니다.

> 이름이 바뀌어도 파일과 데이터는 그대로입니다: 실행 파일 `WindowPiles.exe`, 데이터 폴더 `%LOCALAPPDATA%\WindowPiles`, 배포 zip `WindowPiles-<버전>-win-x64.zip`.

- 명세: [Desktop_Window_Piles_MVP_Spec_v1.0.md](Desktop_Window_Piles_MVP_Spec_v1.0.md)
- 개발 계획: [Development_Plan_v1.md](Development_Plan_v1.md)
- P0 PoC 결과: [docs/poc-results.md](docs/poc-results.md)

> **미리 보기(베타) 버전입니다.** 매일 쓰면서 다듬는 중이라 동작이 바뀔 수 있습니다. 이 앱은 다른 앱의 창을 숨기기만 하고 닫거나 종료하지는 않습니다.

## 설치

**지원 OS:** Windows 11, Windows 10 22H2 (64비트). 설치 프로그램과 관리자 권한이 필요 없고, 따로 설치할 구성요소도 없습니다.

1. [Releases](../../releases/latest) 페이지에서 `WindowPiles-<버전>-win-x64.zip`을 내려받습니다.
2. 압축을 풀어 **계속 둘 폴더**에 `WindowPiles.exe`를 넣습니다. 예: `%LOCALAPPDATA%\Programs\WindowPiles`
   - Windows 로그인 시 이 위치의 exe가 자동 실행되므로, '다운로드' 폴더처럼 나중에 정리할 수 있는 곳은 피하는 것이 좋습니다.
   - 나중에 exe를 옮겼다면 옮긴 exe를 한 번 실행하세요. 자동 실행 경로가 새 위치로 바뀝니다.
3. `WindowPiles.exe`를 더블클릭합니다.
   - **"Windows의 PC 보호" 파란 창이 뜨면** `추가 정보` → `실행`을 누릅니다. 아직 코드 서명을 하지 않은 앱이라 처음 한 번 뜨는 경고입니다.
4. 화면 가운데에 사용법 창이 뜨면 설치가 끝난 것입니다. 작업 표시줄 오른쪽 아래 트레이에 아이콘이 생깁니다.
   - Windows 11은 새 트레이 아이콘을 `^` 안에 숨깁니다. 아이콘을 작업 표시줄로 끌어 두면 늘 보입니다.

**업데이트:** 트레이 아이콘 우클릭 → `Neverflow 종료`(v0.2.1 이하는 `종료`) 후 새 `WindowPiles.exe`로 덮어쓰고 다시 실행합니다. 종료할 때 숨긴 창은 모두 꺼내 두고, 다시 실행하면 같은 창들이 원래 더미로 다시 접힙니다. 더미 이름, 색, 위치도 그대로입니다.

**삭제:**
1. 트레이 아이콘 우클릭 → `Windows 시작 시 자동 실행`을 끕니다.
2. `Neverflow 종료`(v0.2.1 이하는 `종료`)를 누릅니다. 숨겨 둔 창은 모두 화면으로 돌아옵니다.
3. `WindowPiles.exe`를 지웁니다.
4. 저장된 더미 정보도 지우려면 `%LOCALAPPDATA%\WindowPiles` 폴더를 지웁니다.

## 사용법

**실행:** `WindowPiles.exe`를 더블클릭합니다. 소스에서 빌드했다면 `build\bin\Release\WindowPiles.exe`입니다.
- 처음 실행하면 화면 가운데에 사용법 창이 뜹니다.
- 트레이(화면 오른쪽 아래) 아이콘을 누르거나 exe를 한 번 더 실행하면 사용법 창을 다시 볼 수 있습니다.
- 처음 실행할 때부터 **Windows 로그인 시 자동 실행**이 켜집니다. 트레이 메뉴에서 끌 수 있습니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 창을 더미에 넣기 | 창 제목줄을 잡고 끌면 **모든 모니터의 위쪽 가운데**에 `＋ 새 더미` 칸이 나타납니다. 거기에 놓으면 창이 들어가고 그 모니터 오른쪽 위에 더미 카드가 생깁니다 |
| 같은 더미에 더 넣기 | 다른 창을 끌어서 **카드 위에** 놓습니다 (카드 테두리가 진하게 강조됨) |
| 펼치기 (작업 시작) | 카드를 **한 번 클릭**하면 창들이 원래 자리로 펼쳐집니다. 화면 가장자리에 더미 색 테두리가, 맨 위에 `● 이름 작업 중 · 접기` 이름표가 생깁니다. 다른 더미를 펼치면 지금 더미는 자동으로 접힙니다 |
| 접기 | 맨 위 **이름표를 클릭**하면 창들이 원래 카드 자리로 모여 접힙니다 |
| 펼친 더미에 더 넣기 | 창을 끌면 맨 위 이름표가 **`＋ 여기에 놓아 '이름'에 넣기`로 커집니다**. 거기에 놓으면 창은 원래 자리에 열린 채로 더미에 들어갑니다 |
| 더미에서 창 하나 빼기 | 펼친 더미에 속한 창을 끌면 `＋ 새 더미` 오른쪽에 **`－ 이 더미에서 빼기`** 칸이 나타납니다. 거기에 놓으면 창은 원래 자리에 그대로 남고 더미에서만 빠집니다 |
| 이름만 빠르게 바꾸기 | 카드 타이틀바의 **이름 위에 마우스를 올리면 연필 아이콘**이 나타납니다. 누르면 그 자리에서 입력합니다 (Enter 저장, Esc 취소, 비우면 자동 이름) |
| 이름·색 바꾸기 | 카드(또는 이름표) **우클릭 → 이름·색 바꾸기…**. 프리셋 10색 또는 `+`로 원하는 색을 직접 고릅니다 |
| 더미 옮기기 | 카드를 끌어서 다른 곳(다른 모니터도 가능)에 놓습니다. 화면 가장자리에 붙습니다 |
| 더미 풀기·모두 꺼내기·종료 | 카드 우클릭 메뉴, 또는 트레이 아이콘 우클릭 메뉴 |
| 오늘 어떤 작업에 시간을 썼는지 보기 | 트레이 아이콘(또는 더미) 우클릭 → **작업 기록**. 더미를 펼쳐 둔 시간이 하루 타임라인, 더미별 합계, 최근 7일 막대로 보입니다. 화면 잠금, 절전, 5분 넘게 자리를 비운 시간은 빠집니다. 날짜는 ‹ › 또는 ←/→ 키로 바꿉니다 |
| 접어 둔 메일·메신저의 새 알림 확인 | 따로 할 일 없음. 더미 안의 창에 새 알림이 오면 카드 **오른쪽 위에 빨간 배지**가 붙습니다. 제목에 안 읽음 수가 있는 앱(예: `(3) …`, `받은 편지함 (7)`)은 숫자, 작업 표시줄을 깜빡이기만 하는 앱은 점으로 표시됩니다. 펼쳐서 창을 보면 사라집니다 |

**재시작·업데이트·재부팅 후에도 유지**
- 더미의 이름, 색, 위치, 접힘 상태, 들어 있는 창 정보를 `%LOCALAPPDATA%\WindowPiles\piles.json`에 저장합니다. 미리보기 사진은 저장하지 않습니다.
- **앱을 종료하거나 업데이트 후 다시 실행:** 종료할 때 숨긴 창을 모두 꺼내 두었다가, 다시 실행하면 같은 창들을 원래 더미로 다시 접습니다.
- **재부팅이나 강제 종료 뒤:** 로그인하면 자동 실행되어 더미가 그대로 나타납니다. 그사이 닫힌 앱의 창은 카드 안 **"다시 열어야 할 창"** 목록에 보입니다.
  - 더미를 펼치면 목록의 앱들이 한 번에 다시 실행되고, 앱마다 새로 뜬 첫 창이 그 더미에 열린 채로 들어갑니다. 항목 하나만 누르면 그 앱만 실행됩니다.
  - 앱은 문서 없이 열립니다(예: 빈 Excel). 1분 안에 창이 뜨지 않은 앱은 그 창을 카드에 끌어 넣으면 목록에서 사라집니다.
  - 필요 없으면 우클릭 → `닫힌 창 목록 지우기`로 지웁니다.
- **앱이 꺼진 경우:** 접혀 있던 창의 앱이 실행 중에 종료돼도 같은 목록으로 옮겨집니다. 펼쳐 둔 창을 사용자가 직접 닫은 경우는 더미에서 그냥 빠집니다.

**안전장치**
- **프로그램이 비정상 종료되면:** 감시 프로세스가 앱을 즉시 다시 실행하고, 더미는 접힌 그대로 이어집니다. 크래시가 반복되거나 '작업 끝내기'로 끈 경우에는 숨긴 창을 모두 되돌립니다.
- **둘 다 죽었다면:** 다음 실행 때 되돌립니다. Windows에도 재시작 대상으로 등록돼 있어 크래시·업데이트·Windows Update 재부팅 후 자동으로 다시 실행됩니다.
- **Windows를 끄거나 로그아웃할 때:** 더미 상태를 저장한 뒤 숨긴 창을 모두 꺼냅니다. 그래서 각 앱의 "저장할까요?" 창이 정상적으로 보입니다.
- **다른 앱이 얼어 있어도 멈추지 않습니다.** 절전 중이라 응답하지 않는 앱이 있어도 창 복원은 백그라운드로 처리되고, 그 앱이 깨어나면 바로 창이 나타납니다.
- **다른 앱 안에서 실행해도 안전합니다.** 패키지 앱(예: 일부 IDE·터미널) 안에서 실행하면 저장 위치가 그 앱 전용으로 바뀌므로, 자동으로 Windows 셸을 통해 일반 앱으로 다시 실행합니다.
- 창을 강제로 닫거나 앱을 종료하지 않습니다.
- 진단 로그: `%LOCALAPPDATA%\WindowPiles\app.log` (창 내용은 기록하지 않음)

**작업 기록과 개인정보**
- 기록은 이 PC의 `%LOCALAPPDATA%\WindowPiles\activity\`에만 날짜별 파일(`2026-10-22.tsv`)로 남습니다. 인터넷으로 보내지 않습니다.
- 더미 이름과 펼치고 접은 시각만 적고, 창 제목이나 내용은 적지 않습니다.
- 작업 기록 창에서 `기록 끄기`로 멈출 수 있고, `기록 폴더 열기`로 파일을 열어 엑셀에서 볼 수 있습니다.

**넣을 수 없는 창:** 관리자 권한으로 실행된 앱, 대화상자, 작업 표시줄·바탕화면 같은 시스템 창. 이런 창을 끌면 바에 "이 창은 넣을 수 없어요"가 표시됩니다.

**아직 없는 기능:** 미리보기 부채 펼침, 되돌리기, 창 모두 닫기, 단축키, 전체화면 자동 숨김. ([개발 계획](Development_Plan_v1.md) P1~P2 참고)

## 빌드

필요: Visual Studio 2022 또는 Build Tools 2022 (C++ 데스크톱 워크로드, Windows SDK 10.0.22621 이상)

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

결과물: `build\bin\Release\`

배포 zip 만들기 (빌드 포함): `powershell -ExecutionPolicy Bypass -File scripts\package.ps1 -Version 0.1.1` → `build\dist\WindowPiles-0.1.1-win-x64.zip`. 확인 후 `gh release create v0.1.1 <zip>`로 올립니다.

## 구성

| 경로 | 내용 |
|---|---|
| `src/app/` | 진입점(`--watchdog`·`--autostart`), 앱 코어(더미 관리·접기/펼치기·저장/복원·트레이), 아이콘 |
| `src/interaction/drag_watcher.*` | 다른 앱 창 끌기 감지(WinEvent, 주입 없음) + 모니터별 상단 놓는 곳 바 |

| `tests/e2e/e2e_perf.cpp` | 부하 측정: 큰 창 N개 한 더미의 시작·펼치기·접기·로그아웃 시간, 앱 응답 지연, 메모리 |

E2E 테스트 실행:
- **공통:** `WindowPiles.exe`는 **꺼 둔 상태**여야 합니다. 테스트는 별도 데이터 폴더(`build\bin\Release\e2e-data`)를 쓰므로 실제 더미 상태는 건드리지 않습니다.
- **UI E2E:**
  1. `TestWindows.exe --normal 3`을 띄웁니다.
  2. `e2e_piles.exe`를 실행합니다. 테스트가 앱을 직접 켜고 끕니다.
  3. **마우스와 키보드가 약 40초간 자동으로 움직입니다.**
- **수명주기:** `e2e_lifecycle.exe`만 실행하면 됩니다(약 45초).
- **배지:** `e2e_badges.exe`만 실행하면 됩니다(약 15초). 수명주기 테스트와 연달아 돌리지 말고 하나씩 실행하세요. 화면 픽셀을 읽으므로 화면이 잠겨 있으면 실패합니다.
- **부하 측정:** `e2e_perf.exe 40`(창 개수). 다른 버전과 비교하려면 `e2e_perf.exe 40 경로\WindowPiles.exe`처럼 exe를 지정합니다.

- 화면 = 책상(Deskterior) 컨셉: 따뜻한 잉크색 무채색, 그림자도 따뜻한 톤입니다. 사용법 창 머리에 마크와 슬로건이 들어갔습니다.

- 탐색기, 바로가기, 작업 표시줄 고정에서도 exe 아이콘이 새 마크로 보입니다.

- **더미 이름 입력창에서 Ctrl+A로 전체 선택**할 수 있습니다.
- **더미 카드가 20% 높아졌습니다.** 미리보기 띠가 각 창의 위쪽을 더 많이 보여 주고, 카드 뒤에 겹쳐 보이던 종이를 없애 한 장으로 깔끔하게 보입니다.

### v0.2.1 — 2026-10-22

> 더 많이 올려 두고, 놓아 둔 그대로.

**✨ 바뀐 점**
- **더미 카드가 60% 높이로 작아졌습니다.** 미리보기는 각 창의 윗부분(탭·주소창·제목줄) 띠로 보여줍니다. 그래서 화면 한쪽에 카드를 거의 두 배 더 놓을 수 있습니다.
- **겹쳐 둔 순서를 기억합니다.**
  - 겹쳐 놓은 더미 카드는 펼쳤다 접어도 원래 층으로 돌아갑니다.
  - 더미 안 창들도 접기 전에 맨 앞이던 창이 다시 맨 앞으로 펼쳐집니다. 재시작해도 유지됩니다.

**🐛 고친 문제**
- 더미에 끌어다 놓은 창이 나중에 펼치면 카드 근처나 화면 밖에 나타나던 문제(v0.2.0). 이제 끌기 전 자리로 돌아오고, 화면 밖으로 벗어나 있으면 화면 안으로 옮깁니다.

### v0.2.0 — 2026-10-22

> 창이 많아도 가볍게, 그리고 하루를 어디에 썼는지 한눈에.

**✨ 새 기능**
- **작업 기록.** 더미를 펼쳐 둔 시간을 업무 시간으로 기록합니다. 트레이나 더미를 우클릭하고 `작업 기록`을 누르면 볼 수 있습니다.
  - **하루 흐름:** 언제 어떤 더미를 펼쳤는지 보여주는 타임라인
  - **더미별 합계:** 오래 쓴 순서로 정렬
  - **최근 7일:** 날짜별 막대 그래프
  - **빼는 시간:** 화면 잠금, 절전, 5분 넘게 자리를 비운 시간
  - **보관 방식:** 이 PC에만 날짜별 파일로 남고, 창 제목과 내용은 기록하지 않습니다.

**⚡ 성능** (큰 창 40개를 한 더미에 넣고 측정)

| | v0.1.0 | v0.2.0 |
|---|---|---|
| 접기 | 2.1~3.9초 | **0.5~0.7초** |
| 펼치기 중 앱 멈춤 | 0.7~0.9초 | **0.2~0.3초** |
| 시작하며 다시 접기 | 2.7~3.2초 | **0.7~0.9초** |
| 최대 메모리 | 43~50MB | **17MB** |

- 미리보기는 카드에 보이는 앞쪽 3개 창만 찍고 보관합니다.
- 창 복원은 앞쪽 창부터 몇 개씩 나눠서 합니다.
- 저장은 한 번에 모아서 하고, 파일 쓰기는 백그라운드에서 합니다.
- 로그인 직후 자동 실행이 더 빨라졌습니다.

**🐛 고친 문제**
- 더미를 접은 직후 알림 배지가 잘못 뜨던 문제
- 비정상 종료 뒤 일부 숨긴 창이 다시 나타나지 않을 수 있던 문제
- 재부팅할 때마다 '다시 열어야 할 창' 목록이 계속 늘어나던 문제 (이제 더미당 최근 20개만 남깁니다)

### v0.1.0 — 2026-10-21

> 첫 미리 보기 버전.

- **더미 만들기와 넣기:** 창을 끌어 화면 위쪽 `＋ 새 더미`에 놓으면 더미가 생깁니다. 카드에 놓으면 같은 더미에 들어갑니다.
- **펼치기와 접기:** 카드를 클릭하면 펼치고, 맨 위 이름표를 클릭하면 다시 접습니다. 펼친 동안에는 화면 테두리와 이름표로 '작업 중'을 표시합니다.
- **이름과 색:** 이름은 타이틀 위 연필로 바로 바꿉니다. 색은 프리셋 10색 또는 직접 고른 색을 씁니다.
- **창 하나 빼기:** `－ 이 더미에서 빼기` 영역에 놓으면 그 창만 빠집니다.
- **여러 모니터 지원**
- **알림 배지:** 접어 둔 메일·메신저에 새 알림이 오면 빨간 숫자나 점 배지로 알려줍니다.
- **더미 유지:** 앱 재시작, 업데이트, 재부팅, 절전, 로그아웃 뒤에도 더미가 그대로 남습니다. 닫힌 앱은 '다시 열어야 할 창' 목록에 보입니다.
- **비정상 종료 대비:** 감시 프로세스가 앱을 다시 실행하거나 숨긴 창을 되돌립니다.
