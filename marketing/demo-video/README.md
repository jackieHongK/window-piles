# 창 더미 — 20초 데모 영상 시안 (Remotion)

직무별 유스케이스([../usecases.md](../usecases.md))를 바탕으로 만든 **100% 모션그래픽** 시안 7편입니다.
- 사양: 1920×1080, 30fps, 20초
- 직무: PM, 마케터, MD, 영업, 디자이너, 개발자, 회계/재무

## 구성 (공통 20초)

| 구간 | 프레임 | 내용 |
|---|---|---|
| 훅 | 0–90 | 창이 쏟아지고 "다음에… 뭐 해야 하지?" |
| 문제 1·2·3 | 90–240 | 최소화하면 잊음 / 가상 데스크톱이면 안 보임 / 다 띄우면 정신없음 |
| 해결책 | 240–300 | 창들이 색 카드 더미로 모임, "일을 '더미'로 접어 두세요" |
| 사용 흐름 | 300–510 | 더미 A 펼침 → 급한 알림 → 더미 B로 전환(A는 카드로 접힘) → B 접기 → A로 복귀 |
| 마무리 | 510–600 | "일은 쌓아 두되, 잊지는 않게." + 로고 |

## 실행

```bash
npm install
```

미리보기 (브라우저에서 시안을 고르고 타임라인을 넘겨 볼 수 있음):

```bash
npm run studio
```

7편 모두 MP4로 렌더링 → `out/<직무>.mp4`:

```bash
npm run render:all
```

검토용 정지 화면 → `out/stills/`:

```bash
node render-all.mjs --stills --only pm,md
```

## 수정 포인트
