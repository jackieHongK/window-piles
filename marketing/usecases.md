# 창 더미 — 직무별 유스케이스 기획 (데모 영상용)

> 공통 메시지: **"최소화하면 잊어버리고, 가상 데스크톱에 넣으면 안 보이니 잊혀지고, 다 띄워 두면 정신없다."**
> 하던 일을 멈추고 급한 일로 넘어갔다가 다시 돌아오는 걸 하루에 수십 번 반복하는 멀티태스커를 위해, 직접 만든 도구.

## 공통 20초 구성 (30fps, 600프레임, 1920×1080)

| 구간 | 시간 | 장면 | 화면 문구 |
|---|---|---|---|
| ① 훅 | 0~3초 | 직무별 창들이 쏟아지며 화면이 꽉 참. 인물 칩(이름·요일·시각) | **"다음에… 뭐 해야 하지?"** |
| ② 문제제기 | 3~8초 | 3컷 빠르게 전환: 최소화 → 가상 데스크톱 → 다 띄우기 | 각 컷에 직무별 한 줄 + 스티커 |
| ③ 해결책 | 8~10초 | 흩어진 창들이 색 카드 더미 3개로 착착 모임 | **"일을 '더미'로 접어 두세요"** |
| ④ 사용 흐름 | 10~17초 | 더미 A 펼침(색 테두리 + 맨 위 이름표) → 급한 알림 → 더미 B 펼침, A는 카드로 자동 접힘 → B 접기 → A로 복귀 | "펼치면 바로 그 일로" / "급한 일이 끼어들면" / "하던 일은 카드로 남아요" / "끝나면 그대로 복귀" |
| ⑤ 마무리 | 17~20초 | 카드 3개가 가지런히 놓인 화면 + 로고 | **"일은 쌓아 두되, 잊지는 않게."** |

**연출 원칙**
- 실제 앱 동작만 보여주고, 카메라·속도·효과만 과장합니다.
- 창은 특정 브랜드가 아닌 범용 모양(브라우저·시트·문서·메신저·코드…)으로 그립니다.
- 무채색 바탕(앱 디자인 토큰) + 비비드 스티커(노랑·핑크·라임)로 "세련된 키치" 톤을 냅니다.

## 1. PM (서비스 기획자) — "지은, 화요일 오전 10:42"
- **상황:** 다음 스프린트 기획서를 쓰는 중에 결제 장애가 터지고, 오후엔 주간 보고 마감까지.
- **더미**
  - 🗂 **3월 스프린트 기획** (파랑) — 이슈 보드, 화면 설계, 기획서
  - 🔥 **결제 오류 대응** (빨강) — 메신저 장애 채널, 모니터링 대시보드, 서버 로그
  - 📊 **주간 보고** (초록) — 지표 시트, 보고 슬라이드
- **끼어드는 일:** 메신저 "🚨 결제 실패율 12% 급증, 확인 부탁드려요"
- **문제제기 한 줄:** 최소화 "기획서 어디 뒀더라?" / 가상 데스크톱 "장애 채널이 데스크톱 3에…" / 다 띄움 "창 23개, 탭 61개"

## 2. 퍼포먼스 마케터 — "민호, 수요일 오후 2:15"
- **상황:** 봄 시즌 캠페인 예산을 조정하는데 인플루언서 원고 검수가 급하게 들어옴.
- **더미**
  - 🎯 **봄 시즌 캠페인** (주황) — 광고 관리자, 분석 대시보드, 소재 폴더
  - 🤝 **인플루언서 협업** (분홍) — 메신저 DM, 계약서 PDF, 섭외 시트
  - 📈 **월간 리포트** (보라) — 성과 시트, 보고 슬라이드
- **끼어드는 일:** 메신저 "내일 업로드 전에 원고 확인 부탁드려요!"
- **문제제기 한 줄:** 최소화 "ROAS 보던 창이 어디…" / 가상 데스크톱 "계약서 열어둔 거 까먹음" / 다 띄움 "대시보드만 7개"

## 3. MD (이커머스 상품기획) — "수빈, 목요일 오전 9:30"
- **상황:** 신상 기획전 오픈 준비 중에 베스트 상품 재고 품절 경보.
- **더미**
  - 🛍 **신상 기획전 오픈** (파랑) — 상품 등록 어드민, 상세페이지 시안, 가격표 시트
  - 📦 **재고 부족 대응** (빨강) — 재고 시트, 협력사 메일, 발주서
  - 🏷 **프로모션 정산** (초록) — 정산 시트, 쿠폰 대시보드
- **끼어드는 일:** 메일 "베스트 상품 B-102, 이번 주 품절 예정입니다"
- **문제제기 한 줄:** 최소화 "가격표 수정하다 말았는데…" / 가상 데스크톱 "발주서는 어디 데스크톱?" / 다 띄움 "엑셀만 9개"

## 4. B2B 영업 — "태준, 월요일 오후 1:50"
- **상황:** A사 견적서를 마무리하는데 B사가 오늘 미팅을 당기자고 함. C사 계약 검토도 대기 중.
- **더미**
  - 💰 **A사 견적** (초록) — 견적 시트, 단가표, 고객 메일
  - 📞 **B사 긴급 미팅** (주황) — 고객 관리(CRM), 제안서 슬라이드, 회의록
  - 📝 **C사 계약 검토** (회색) — 계약서 문서, 법무팀 메일
- **끼어드는 일:** 메신저 "B사: 오늘 3시로 미팅 당겨도 될까요?"
- **문제제기 한 줄:** 최소화 "견적 단가 어디까지 넣었지?" / 가상 데스크톱 "제안서는 데스크톱 2에…" / 다 띄움 "메일 창만 6개"

## 5. 프로덕트 디자이너 — "하린, 금요일 오전 11:05"
- **상황:** 홈 화면 리뉴얼 시안 작업 중에 개발팀 QA 수정 요청이 쏟아짐.
- **더미**
  - 🎨 **홈 리뉴얼 시안** (보라) — 디자인 툴, 레퍼런스 폴더, 무드보드
  - ✏️ **QA 수정 요청** (분홍) — 메신저 피드백, 이슈 보드
  - 📦 **에셋 전달** (파랑) — 내보내기 폴더, 공유 드라이브
- **끼어드는 일:** 메신저 "버튼 간격이 시안이랑 달라요, 확인 부탁!"
- **문제제기 한 줄:** 최소화 "레퍼런스 폴더 어디 갔지?" / 가상 데스크톱 "무드보드를 잊고 있었다" / 다 띄움 "아트보드보다 창이 더 많음"

## 6. 개발자 — "도윤, 화요일 오후 4:20"
- **상황:** 검색 기능을 개발하던 중 운영 에러 알림, 그 와중에 코드 리뷰 요청.
- **더미**
  - 💻 **검색 기능 개발** (파랑) — 코드 에디터, 터미널, 로컬 브라우저
  - 🚨 **운영 핫픽스** (빨강) — 에러 모니터링, 로그
  - 👀 **코드 리뷰** (회색) — 풀 리퀘스트, 변경 사항
- **끼어드는 일:** 알림 "🔴 에러 342건: NullPointerException (결제 API)"
- **문제제기 한 줄:** 최소화 "터미널 어느 창이었더라?" / 가상 데스크톱 "리뷰 요청 3일째 방치" / 다 띄움 "터미널 탭 14개"

## 7. 회계/재무 — "서연, 월말 오후 3:40"
- **상황:** 3월 결산 마감 중인데 영업팀이 세금계산서 발행을 급하게 요청, 경비 정산도 밀려 있음.
- **더미**
  - 🧾 **3월 결산** (초록) — 회계 시스템(ERP), 결산 시트, 증빙 폴더
  - ⚡ **세금계산서 발행** (주황) — 발행 화면, 거래처 메일
  - 💳 **경비 정산** (보라) — 영수증 폴더, 정산 시트
- **끼어드는 일:** 메신저 "오늘 중으로 세금계산서 발행 부탁드려요!"
- **문제제기 한 줄:** 최소화 "결산 시트 몇 행까지 했지?" / 가상 데스크톱 "증빙 폴더가 안 보여요" / 다 띄움 "숫자가 다 숫자로 보임"
