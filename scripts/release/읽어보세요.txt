Stack Neverflow {VERSION} 미리 보기 (창 더미, 이전 이름 Window Piles)

설치
1. 이 폴더의 WindowPiles.exe를 계속 둘 곳에 옮깁니다.
   예: %LOCALAPPDATA%\Programs\WindowPiles
   (Windows 로그인 시 그 위치의 exe가 자동 실행됩니다.)
2. WindowPiles.exe를 더블클릭합니다.
   "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   아직 코드 서명을 하지 않은 앱이라 처음 한 번 뜨는 경고입니다.
3. 화면 가운데에 사용법 창이 뜨면 설치가 끝난 것입니다.

사용
- 창 제목줄을 끌면 화면 위쪽에 [＋ 새 더미]가 나타납니다. 거기에 놓으면 더미가 생깁니다.
- 카드를 한 번 클릭하면 펼치고, 맨 위 이름표를 클릭하면 다시 접습니다.
- 트레이 아이콘을 누르면 사용법을 다시 볼 수 있습니다.
- 트레이 아이콘 우클릭 → [작업 기록]에서 더미별로 쓴 시간을 볼 수 있습니다.

업데이트
- 트레이 아이콘 우클릭 → [종료] → 새 exe로 덮어쓰기 → 다시 실행.
  더미는 그대로 유지됩니다.

삭제
- 트레이 아이콘 우클릭 → [Windows 시작 시 자동 실행] 끄기 → [종료] → exe 삭제.
- 저장된 더미 정보와 작업 기록까지 지우려면 %LOCALAPPDATA%\WindowPiles 폴더를 지웁니다.
